# Reading notes

One file per source, named by BibTeX citekey — `author2024keyword.md`.

Use the template in [`../README.md`](../README.md). Two fields carry real weight:

- **`verified_against_source`** — `false` means the note has not been checked against the
  primary source and may not be cited anywhere in this repository.
- **"Does this pre-empt H2?"** — every source gets asked directly. The literature review is
  the aggregate of these answers.

Notes are your own words. Summaries and critique, not extended quotation. The source PDFs
stay in your reference manager, outside this repository.
