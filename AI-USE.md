# AI Use Disclosure

This research programme studies human–AI collaboration, and it is itself produced through
human–AI collaboration. That is disclosed here deliberately and in detail, because a
reviewer will notice it, and because a study of epistemic agency that hid its own
dependence on AI would be self-refuting.

## Authorship

**AI systems are not authors of this work.** Authorship requires accountability for the
claims made, and no current AI system can bear that. All intellectual responsibility for
the hypotheses, the design decisions, and the errors rests with the human author.

Any earlier version of this repository suggesting joint human–AI maintainership is
superseded by this file.

## Where AI was used

| Activity | AI involvement | Human responsibility |
|---|---|---|
| Idea generation | Substantial — dialogue, challenge, reframing | All ideas retained or rejected by the author |
| Structuring the research programme | Substantial — the epistemic-status system and the 2×2 coupling reframe emerged in dialogue | Accepted after review |
| Drafting documentation | Substantial — most prose in this repo is AI-drafted from author dialogue | Reviewed and edited by the author |
| Translation (VI ↔ EN) | Substantial | Verified by the author, who is bilingual |
| Literature search | *Not yet performed* | — |
| Literature summarisation | *Not yet performed* | Summaries must be verified against primary sources before use |
| Study design | *Not yet performed* | — |
| Data collection | **None. Prohibited.** No human-subjects data exists. | — |
| Data analysis | *Not yet performed* | Any AI-assisted analysis will be reported with code, seeds, and versions |
| Statistical inference | *Not yet performed* | — |

This table is updated as the programme progresses. An entry marked *not yet performed*
that becomes active must be revised in the same commit as the work it describes.

## Verification commitments

- **No citation enters this repository without being checked against the primary source.**
  AI-generated reference lists are treated as leads, not as bibliography.
- **AI-summarised findings are marked as such** in `lit/notes/` until the author has read
  the source.
- **Analysis code is version-controlled and reproducible** regardless of how it was
  written.

## Reflexivity note

The author is the first — and currently only — subject of this programme. Interaction
history with AI systems during the production of this repository is a legitimate object of
study (an N=1 autoethnographic pilot), and may be logged as such. It is **not** evidence
for any hypothesis. See the cite-downward rule in `CLAUDE.md` §4.
